## v0.9.136
Changes since `v0.9.135`, including HEAD and working-tree updates.

**Breaking Changes**
- Removed `MastraRequestContextSnapshot`. Low-level chat and approval clients now accept native `RequestContext` from `@mastra/client-js`; `useMastraChat` still accepts plain context objects.

**Features And Fixes**
- Direct Genie chat now receives application context and, when Mastra memory is configured, recalls prior conversations and saves completed question-answer pairs. Genie retains visible conversation history.
- Semantic recall now spans the authenticated resource’s threads and agents.
- Chat transcripts preserve the original question instead of displaying injected context. Server-owned identity fields cannot be overridden by application context, and recall/save failures do not fail the Genie turn.

**Validation**
- Configured release validation completed before this review. No validation commands were rerun; detailed results and counts were not supplied.
