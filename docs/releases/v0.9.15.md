# Release 0.9.15

Version 0.9.15 is a release tooling update. It changes how the project publishes packages to registries so dependent artifacts are published in a defined order, which reduces failures when one package must already exist on the registry before another can publish.

### Release publishing

- Registry dependencies are published sequentially instead of in parallel during release.
- Cargo packaging and publish steps were updated to follow that ordering.
- npm publish logic was adjusted to match the same sequential dependency behavior.
- The generated GitHub release workflow and Rust release workflow wiring were simplified to align with the new publish flow.

### Validation and docs

- npm and Rust release tests were updated for the new publish ordering.
- `AGENTS.md` was updated to describe the sequential registry publish behavior for contributors.
