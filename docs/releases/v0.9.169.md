## v0.9.169
Changes since `v0.9.168`, including HEAD and the working tree; generated-file churn and test-only changes omitted.

**Breaking Changes**
- `ModelCapabilities` requires `reasoning`, `tools`, and `structuredOutput` fields. Update manually constructed capability objects and serialized payloads.

**Improvements And Fixes**
- Model discovery supplements Databricks metadata with models.dev capability data and modelparams.dev reasoning levels, retaining offline fallbacks.
- Reasoning resolution prioritizes published levels over learned errors. Explicit null, disabled, or invalid effort values map to a supported level nearest medium; omitted fields remain unchanged.
- Service installation uses isolated, versioned binaries and Python environments, serializes concurrent installs, and avoids reinstalling satisfied runtime dependencies. Reinstall services to apply these changes.
- macOS service installation clears persisted LaunchAgent disabled overrides.
- Email branding uses a standards-compliant Content-ID and corrected attachment handling for embedded logos.

**Validation**
- The configured release validation phase completed before this review. No checks were rerun; individual outcomes and counts were not supplied.
