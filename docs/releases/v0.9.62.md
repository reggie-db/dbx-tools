**dbx-tools 0.9.62 — Unreleased**
Compared HEAD and the working tree against the latest local tag, `v0.9.61`. Generated-file churn and test-only changes excluded.

**Operator Changes**
- Genie and model gateway support mutually exclusive `--model` and `--model-class` selectors. Gateway requests can omit `model` or select a class through `x-dbx-tools-model-class`.
- Release automation accepts `--release-notes-instructions`. Published documentation includes release notes; generation retains only the current version’s notes.

**Breaking Changes**
- Graphiti removes `--model`, `--embedder-model`, and `--embedder-dimensions`. Use `--model-class` / `MODEL_CLASS` for chat selection; the default is `chat-fast`. Embedding selection and dimensions come from discovery.
- Genie homes change from profile-model-specific paths to profile-only paths. Switching models shares profile state; previous homes are not automatically reused.
- Default chat selection no longer forces the GPT family. Text searches no longer interpret words such as “summarize” or “embedding” as capability classes. Pin an exact model when selection must remain fixed.

**Fixes**
- Default model ranking prefers newer versions within the leading family; chat endpoint searches no longer impose a balanced-class ceiling.
- Missing embedding dimensions are measured through an inference probe. Graphiti uses discovered dimensions and fails explicitly when none are available.
- Chat Thoughts render compact paragraphs and omit Markdown tables.
- Python binding watchers track reachable source dependencies, reducing regeneration from unrelated edits.

**Validation**
- 79 focused tests passed across seven files; zero failures.
- `bun run version:check` and `git diff v0.9.61 --check` passed.
- Full builds, Python runtime tests, and live deployment checks were not run. No files were modified.
