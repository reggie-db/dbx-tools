## v0.9.170
Cumulative changes since `v0.9.167`, including the working tree and unreleased changes from `v0.9.168` and `v0.9.169`.

**Breaking Changes**
- `ModelCapabilities` now requires `reasoning`, `tools`, `structuredOutput`, and `temperature`. Update manually constructed objects and serialized payloads.
- Model Gateway rejects nonnumeric temperature values with HTTP 400. For models with published Databricks temperature policy, it removes unsupported temperature settings or clamps supported values to 0–2.

**Improvements And Fixes**
- Model discovery adds models.dev capability data and modelparams.dev reasoning levels, with committed offline fallbacks. Published reasoning levels take precedence over learned errors; explicit null, disabled, or invalid efforts map to a supported level nearest medium.
- Service installation isolates binaries and Python environments by installation, serializes concurrent installs, and skips satisfied runtime dependencies. Reinstall existing services to apply these changes. macOS installation also clears persisted LaunchAgent disabled overrides.
- Fix Model Gateway service compilation failures caused by missing `@mlflow/core`.
- Fix embedded email-logo attachment handling and use a standards-compliant Content-ID.
- Release-note generation uses the latest successful release workflow as its baseline, retaining product changes from failed release attempts.

**Validation**
- The configured release validation phase completed before this review; detailed outcomes and counts were not supplied. No tests or validation commands were rerun, and no files were modified.
