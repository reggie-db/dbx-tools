## v0.9.186
Cumulative changes since v0.9.185, including the working tree.

**Added**
- Browser debug capture for AppKit, with reusable recording controls, viewport and interaction diagnostics, server-side JSONL storage, and capture IDs for troubleshooting. Enabled automatically in development; configurable through `createApp.debug`.

**Fixed**
- Model Gateway retries requests rejected for invalid encrypted reasoning history after removing replayed reasoning items.
- Chat composer focus no longer triggers browser scrolling; mobile keyboard dismissal and transcript scrolling avoid competing focus-resize adjustments.

**Breaking Changes**
- `copyText` moves from `@dbx-tools/ui-mastra/support` to `@dbx-tools/ui/react`. Update existing imports.

**Validation**
- Configured release validation completed, as reported. No additional tests or validation commands were run; no files were modified.
