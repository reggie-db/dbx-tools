## v0.9.201

**Fixes**
- Model selection no longer marks later point releases, such as Claude Sonnet 4.5, as retired when only an earlier release is retired. Aliases and dated variants of retired releases remain excluded.
- Unresolved model names now report `source: "unmatched"` instead of `"fuzzy-match"`, preserving the catalogue-refresh retry and exposing accurate selection status through Mastra model routes.

**Breaking Changes**
- Model-selection and Mastra route consumers must handle the new `"unmatched"` source value, including exhaustive switches and response validators.

**Validation**
- The configured release validation phase completed, as reported. No additional validation commands were run; no files were modified.
