## v0.9.135
Changes since `v0.9.134`, including HEAD and the working tree.

**Features**
- Add `dbx brand <prompt>` to export `brand.yaml`, research provenance, and downloaded iOS/Android visual references, with profile selection and overwrite protection.
- Support freeform brand briefs and use mobile app icons and screenshots during brand synthesis.

**Fixes**
- Coordinate concurrent web-search availability probes and fall back when Gemini cross-region access is disabled.
- Expand HTML retrieval for asset discovery and support explicit workspace clients for standalone model resolution.

**Breaking Changes**
- Custom `BrandResearchClient` implementations must provide `fetchImage`; custom `BrandResearch` values must include `visualReferences`. Progress consumers must handle the new `visuals` stage.

**Validation**
- Configured release validation completed before this review. No checks were rerun; detailed results and counts were not supplied.
