## v0.9.167
Compared HEAD and working-tree changes with `v0.9.166`; generated churn and test-only changes omitted.

**Fixes**
- `@dbx-tools/appkit-mastra` no longer installs isolated-vm or QuickJS automatically, avoiding unused native-runtime installation failures when Code Mode is disabled.

**Breaking Changes**
- Applications using Code Mode must explicitly install `@mastra/isolated-vm` or `@mastra/quickjs`. Both are now optional peer dependencies; `"auto"` leaves Code Mode disabled if neither is available.
