**v0.9.71 — Changes Since v0.9.70**

**Breaking Changes**
- Replace `@dbx-tools/graphiti` with `@dbx-tools/appkit-graphiti`; import the plugin from the package root. Replace `startGraphitiRuntime()` with `createGraphitiChildProcess()` and use `start()`/`shutdown()`.
- `AppKitChildProcess.start()` now returns `Promise<void>`; await readiness and access the child through `.process`.
- Interceptors remove `bindProcess`, `onTeardown`, and `broadcastSignal`; use `onLifecycle("shutdown", ...)`.
- Web-search provider overrides replace `tool` with `request`. Model settings become GPT preferences after Gemini selection, rather than strict pins.

**Improvements And Fixes**
- Graphiti adds bearer authentication, automatic private sidecar tokens, readiness-gated tools, and structured model-content normalization.
- Web search fixes Gemini request formatting, selects capability-ranked deployed models, and retries with GPT when cross-region restrictions disable Gemini, with a 24-hour runtime cooldown.
- Chat displays live search progress and marks unfinished tools as failed when the assistant stream errors.
- Child-process supervision adds readiness probes, cancellable startup, process-tree cleanup, and signal-preserving foreground execution.
- Mastra skill discovery resolves duplicate names using first-folder precedence. PostgreSQL message-bus startup skips provisioning tables owned by another role.

**Validation**
- The configured release validation phase already completed. No tests or other validation commands were rerun; no counts are reported. Generated churn and test-only changes are excluded.
