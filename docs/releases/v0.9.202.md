## v0.9.202
Cumulative changes since `v0.9.201`, including the working tree.

**Features**
- Model Gateway supports ordered fallback profiles through repeated `--profile` flags. HTTP 429 responses retry the same model through the next available workspace for both direct and translated requests; discovery and routing remain on the first profile.
- Rate-limit cooldowns are shared by workspace and model. They honor upstream retry timing, default to 60 seconds for workspace token limits or 15 seconds otherwise, and automatically restore primary-profile preference.

**Fixes**
- Installed services authenticate every configured fallback profile and preserve the installer’s `PATH` on macOS and Linux so required tools remain discoverable.
- Shared service runtimes remove dependencies no longer declared by any tracked service while preserving other services’ dependencies and legacy unowned entries.
- Translated gateway requests can refresh rejected credentials once. Rate-limit logs explicitly identify the upstream error message.

**Breaking API Changes**
- Resolved gateway `profile` values are arrays; single-string configuration remains accepted. Custom `CliServiceRuntimeInstaller` implementations now receive a service-owner argument.

**Validation**
- Configured release validation completed before this review, as reported. No additional tests or validation commands ran; no files changed.
