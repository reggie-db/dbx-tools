**v0.9.140**
Changes since `v0.9.139`, including HEAD and working-tree changes.

**Added**
- `dbx brand` generates `showcase.html` by default, with responsive desktop/mobile website mockups, brand colors, typography, voice, and visual references. Use `--no-showcase` to disable it.

**Breaking Changes**
- Brand exports now default to a unique temporary directory instead of `./branding`. Pass `--output ./branding` to retain the previous location.

**Fixes**
- Brand research reports web-search, app-store, image-review, and fallback progress instead of leaving those stages silent. Final CLI output includes the export root and showcase path.

**Validation**
- The configured release validation phase completed before this review; detailed results were not supplied. No tests or validation commands were rerun.
