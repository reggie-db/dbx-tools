## v0.9.197

Changes since `v0.9.196`, including the working tree.

**Fixes**
- CLI failures show concise messages and field-specific validation errors instead of internal stack traces. Set `LOG_LEVEL=debug` for cleaned stack traces.
- Subprocess failure summaries omit command arguments and show captured error output on separate lines.
- Projen preserves local VS Code settings during synthesis and restores missing generated defaults. Settings remain editable; comments and formatting are not retained.
- Demo deployment provisions Lakebase schemas and permissions for both Mastra agents, preventing missing-schema and access failures in persistent chat storage.

**Breaking Changes**
- No API removals identified. Scripts that parse subprocess error messages must accommodate the revised format.

**Validation**
- Configured release validation completed before this review. No additional tests or validation commands were run.
