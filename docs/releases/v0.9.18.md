# Release 0.9.18

Version 0.9.18 is a maintenance release focused on how the monorepo builds, packages, and publishes Rust native artifacts and GitHub releases. Application-facing package APIs are largely unchanged; most of the diff is release automation, Projen generators, and contributor documentation. Consumers still get the usual lockstep version bump across npm, PyPI, Cargo, and native binaries tied to this tag.

### Release and CI

- Regenerated the unified GitHub release workflow with a substantially smaller definition, aligned with the updated Rust release pipeline.
- Replaced large generated Rust release JavaScript modules with a structured `.projen/rust-release.json` configuration and new task scripts for workspace compilation and release asset handling.
- Removed the previous standalone Rust release build script and its dedicated test suite in favor of the new compile and asset upload flow.
- Adjusted release planning, release PR preparation, and GitHub release integration in the Projen engine to match the new steps.

### Projen and workspace tooling

- Updated JavaScript, Python, and Rust project release wiring, platform selection, and Rust release workflow generation.
- Refreshed UniFFI Python placement and UniFFI release task output used during binding publication.
- Added automated tests for compile workspace and release assets behavior; updated existing release, Rust project, and UniFFI tests.

### Rust workspace

- Bumped workspace manifest and lockfile entries, including Google crate metadata.
- Updated core build info used by native release binaries.

### Contracts and docs

- Refreshed the generated Model Proxy OpenAPI document shipped with the JavaScript client package.
- Updated `AGENTS.md` and `projen/README.md` to describe the current release and contributor workflow.

### Housekeeping

- Version synchronization and generated Projen or ignore metadata updates accompanying the release preparation commits.
