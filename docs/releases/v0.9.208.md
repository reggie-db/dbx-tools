## Release Notes

Covers `v0.9.206..HEAD` and the working tree.

**Features**
- Model discovery and routing now use `@dbx-tools/dbx-model-catalog` for capabilities, lifecycle status, rankings, latency, limits, and pricing, with a bundled offline snapshot and public catalog refresh.
- Adds reusable AppKit data tables with persisted sorting, filters, column visibility, ordering and sizing, plus lazy row rendering and keyboard-accessible row activation.

**Fixes**
- Restores focused `sync --watch` generation for affected barrels, Python bindings, and the shared Python runtime; full synthesis runs only when required.
- Model selection and gateway listings exclude catalog-deprecated and retired models by default.

**Breaking Changes**
- Replaces model metadata APIs and contracts with direct catalog records: use `catalog()`, route `catalog`, and `hydrateCatalog`. Gateway clients must replace `metadata=true` and response `metadata` with `catalog=true` and `catalog`; standalone status fields are removed.
- Removes Projen’s separate generation-watch tasks and public `watch`/`scaffold` modules. Use `bun run sync -- --watch` for continuous generation.

**Validation**
- The configured release validation phase completed before note generation. No additional validation ran, and no files were modified.
