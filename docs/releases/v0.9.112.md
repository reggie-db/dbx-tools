## Release 0.9.112
Changes since `v0.9.111`, including HEAD and the working tree; generated churn and test-only changes excluded.

- **Breaking changes:** `JsonBlock` and `supportShikiPlugin` are removed from `@dbx-tools/ui-mastra`. Import `JsonBlock`, `createShikiPlugin`, and `highlightToHtml` from `@dbx-tools/ui/react`.
- **Tool previews:** Mastra tool requests, responses, and JSON outputs now show structured record previews with a table/JSON toggle, including objects and arrays encoded as JSON strings.
- **UI fixes:** Record previews improve nested-data layout, long-text wrapping, and scrolling; render empty records instead of blank tables; and syntax-highlight raw JSON. Approval previews now have bounded height.
- **Shared highlighting:** AppKit exposes reusable code-highlighting utilities. Demo search results and bus payloads use highlighted JSON.
- **Validation:** The configured release validation phase completed, as reported. Detailed results and counts were not supplied. No tests or additional validation commands were run; no files were modified.
