## v0.9.178

### Improvements and Fixes
- Model selection supports quality, speed, or cost optimization and structured-output filtering. Chat-only resolution skips unnecessary embedding-dimension probes.
- Thread titles generate alongside chat responses using a bounded, speed-optimized model. Chat remains in a finishing state until title delivery and thread synchronization complete, preventing premature completion and stale sidebar titles.
- Automatic follow-up suggestions use bounded user-request and answer text, a capped output budget, and a structured-output-capable model. Tool payloads are no longer included automatically.
- Feedback routes per message: Genie-backed responses use Genie feedback; other traced responses use MLflow when available. Both use direct ratings with optional written feedback.

### Breaking Changes
- Custom Mastra clients and chat views must replace the single `feedbackMode` field with a `feedbackModes` array; an empty array disables feedback. Server configuration retains `feedbackMode`.
