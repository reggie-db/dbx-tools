## v0.9.188

Changes since `v0.9.187`, including the working tree.

**Features**
- Direct Genie chat can display Genie's original PNG charts with `genieVisualization="image"`, configurable in `MastraChat` or as a server default. Works for live responses and reloaded conversations while retaining the backing query’s Table tab.
- Chart downloads use the viewer’s Databricks identity without exposing credentials in image URLs. If a chart cannot load, the table remains accessible; exports retain the backing table rather than the PNG.

**Fixes**
- Browser debug capture shows a confirmation and the capture ID after successfully copying it.
- Demo chat adds a Genie charts toggle and keeps settings open while changing chat options.

**Compatibility And Validation**
- No breaking changes identified. The default AppKit chart renderer remains unchanged.
- Configured release validation completed before this review, as reported. No additional tests or validation commands were run.
