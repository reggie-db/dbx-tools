## Release 0.9.111
Changes since `v0.9.110`, including HEAD and the working tree; generated churn and test-only changes excluded.

- **Breaking behavior:** Mastra’s auto-created workspaces now enable Monty Python command execution by default. Set `sandbox: false` to retain disabled execution. Monty has no host filesystem, network, shell, environment variables, or third-party packages; explicitly supplied workspaces remain unchanged.
- **Tool routing:** Code Mode instructions now favor direct calls for ordinary tool use, reserving `execute_typescript` for explicit requests or code-based processing.
- **UI fixes:** Single-tool sessions show details without a nested expansion. Code Mode calls display as “Run Workflow.”
- **Validation:** The configured release validation phase completed, as reported. Detailed results and counts were not supplied. No tests or additional validation commands were run; no files were modified.
