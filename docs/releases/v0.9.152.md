## v0.9.152
Changes since `v0.9.151`, including HEAD and the working tree; generated churn and test-only changes omitted.

**Features**
- Projen automatically configures AppKit dependencies, TypeScript inputs, and development/deployment tasks for paired `app` and `server` packages.
- Adds `packageDefaults` for shared options across discovered packages.

**Fixes**
- AppKit deployment uploads an isolated, npm-compatible snapshot with resolved `catalog:` and `workspace:` dependencies, leaving checkout manifests unchanged. The generated `deploy` task validates with Bun and skips CLI-local npm validation.
- Demo deployment retries the known database permission-grant timeout once after 15 seconds and supports cancellation during the retry delay.
- Workspace compilation now includes the root TypeScript configuration.

**Breaking/Behavior Changes**
- AppKit setup activates automatically for paired application/server packages; set `appkit: false` to opt out.
- `publishable: false` now generates `private: true`, preventing accidental npm publication.

**Validation**
- Configured release validation completed before this review, as reported. No validation commands were rerun; detailed results and counts were not provided.
