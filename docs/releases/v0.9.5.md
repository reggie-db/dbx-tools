# Release 0.9.5

Version 0.9.5 is a unified release for the whole monorepo. The main user-visible work is in `dbx-model-proxy`: an embedded metrics dashboard, smarter local rate-limit handling, and layout and branding polish on the dashboard widgets.

### dbx-model-proxy

- Adds an adaptive limits flow and a process-local metrics dashboard (JSON, SSE, Prometheus endpoints plus an embedded UI on the existing listener).
- Ships committed metrics UI assets (GridStack-based layout, branded styles, logos, and status icons) validated via a new `model-proxy:metrics-assets` repository task.
- Extends routing, request logging, throttling, and new `adaptive` and `metrics` modules so admission, 429 handling, and dashboard data stay aligned.
- Makes metrics widgets resizable and persists widget layout (browser `localStorage`, synced across tabs per project design).
- Fixes dashboard branding to use canonical generated brand tokens.
- Aligns widget info controls for clearer dashboard interaction.

### Shared Rust runtime

- Small updates in `dbx-tools-core` logging and library surface used by the proxy build.

### Documentation and contributor workflow

- Documents the model-proxy adaptive rate-limit decay plan under `docs/enhancements`.
- Removes per-component `.release-units` changelogs and the release-please manifest in favor of the single root `VERSION` release model (see `AGENTS.md` updates).
- Drops the ad hoc `test-model-proxy-pat.sh` helper and the `.dev.core-rs.ts` dev hook from the tree.
