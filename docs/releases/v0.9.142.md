## v0.9.142
Compared HEAD and working-tree changes against `v0.9.141`, excluding generated-file churn and test-only changes.

**Features**
- Add opt-in follow-up questions from Genie, model generation, or both. Suggestions are deduplicated, persist with assistant messages, and appear after completed turns. Default limit: three; maximum: ten. Generation failures leave answers unchanged.

**Breaking Changes**
- Post-turn Genie suggestions now default to off. Set `followUpSuggestions: "genie"` to retain native questions, or `true` to combine native and generated questions.
- `useChartChrome()` can return `undefined` before browser theme initialization; custom consumers must handle that state.

**Fixes**
- Prevent initial chart color flicker and incomplete streaming-table rendering.
- Improve Markdown table and bold-text detection, spacing, and multiline layout in record previews.

**Validation**
- Configured release validation completed before this review, as reported. Detailed results were not supplied; no tests or validation commands were rerun. No files were modified.
