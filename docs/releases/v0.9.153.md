# v0.9.153
Changes since `v0.9.152`, including HEAD and the working tree; generated churn and test-only changes omitted.

**Breaking Changes**
- AppKit workspaces now generate read-only `vite.config.ts` files. Move custom settings to `vite.config.override.ts`.
- Package discovery defaults change: JavaScript prefers `packages/js` when present; Python automatically includes direct children containing `src/`. Set `packageRoots` or `discoverPackages: false` to retain explicit selection.

**Improvements And Fixes**
- AppKit deployment adds strict bundle validation, active-run protection, and stale-state recovery limited to the temporary upload snapshot; duplicate CLI npm validation and tests are skipped by default.
- Failed AppKit deployments and demo startup attempts print recent app logs while preserving the original failure.
- Terminal `app` and `server` directories receive the correct runtime roles beneath generic parent directories.
- Workspace generation adds root TypeScript configuration overrides, preserves repository metadata when Git discovery is unavailable, and stops ignoring authored `src/lib` files.
- CLI argument utilities add schema-based `parseArgv` for standalone commands.

**Validation**
- Configured release validation completed before this review, as reported. No checks were rerun; detailed outcomes and counts were not supplied.
