**v0.9.141 — Changes Since v0.9.140**

**Breaking Changes**
- Mastra Code Mode is now disabled by default. Set `codeMode: "auto"` to enable automatic transport selection.
- `codeMode: true` is no longer supported. Use `"auto"`, `"isolated-vm"`, `"quickjs"`, or an options object with a required `transport` field.

**Fixes**
- Both Code Mode transports are optional and dynamically loaded, avoiding mandatory QuickJS runtime requirements and bundler dependencies on unselected transports.
- Automatic selection prefers isolated-vm, falls back to QuickJS, and disables Code Mode if neither can run. Explicit transport selections fail during startup with actionable errors.
- The demo explicitly enables automatic Code Mode selection.

**Validation**
- The configured release validation phase completed before this review. Detailed results and counts were not supplied; no tests or validation commands were rerun.
