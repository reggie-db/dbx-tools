# Release 0.9.13

Release 0.9.13 improves day-to-day installs behind corporate npm mirrors, adds typed model-proxy operator APIs, and introduces a reusable service lifecycle with an optional native tray companion.

### @dbx-tools/core

- Adds a dependency resolver that walks declared npm dependencies against the configured registry (including corporate mirrors) so version and missing-dependency checks work without assuming the public npm index.
- Extends registry discovery in project utilities and documents the new resolver APIs in the package README.
- Updates binary install helpers and tests so release tooling and `bin.ensure` stay aligned with registry-aware resolution.

### Model proxy (`dbx model-proxy`)

- Exposes retained state and demand-aware live feeds through typed GraphQL at `/graphql`, with configured GraphiQL examples, WebSocket subscriptions, and schema introspection on the same endpoint.
- Restores loopback auth and rate-limit controls with same-origin mutation protection.
- Generates YAML and JSON OpenAPI documents plus Scalar docs from aide and typed Axum routes.
- Ships a small `dbx-model-proxy-tray` companion for address display and profile selection without a WebView or frontend asset bundle.
- Adds a generated `@dbx-tools/openapi-model-proxy` client package.

### Service lifecycle (`dbx-tools-service`)

- Adds reusable optional tray, GraphQL, retained-topic, and OpenAPI modules to `dbx-tools-service`.
- Keeps service registration, persistence, managed executable copies, and companion autostart in one source-only crate.

### Native release binaries (`@dbx-tools/rust-binary`)

- Adjusts release binary metadata and install flow so the model proxy can ship its tray companion alongside the headless service.

### Monorepo and release

- Bumps workspace versions and lockfiles across Rust and JavaScript packages for the unified 0.9.13 release.
- Extends the shared OpenAPI generator and watcher to consume recorded Rust producers without observing its generated output.
- Updates root and package documentation, archives a completed model-proxy rate-limit enhancement plan, and refreshes in-repo agent guidance.
