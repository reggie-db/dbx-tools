# Release 0.9.13

Release 0.9.13 improves day-to-day installs behind corporate npm mirrors, ships a native desktop experience for the model proxy with a simpler menu bar, and refreshes how background services pick and package their UI.

### @dbx-tools/core

- Adds a dependency resolver that walks declared npm dependencies against the configured registry (including corporate mirrors) so version and missing-dependency checks work without assuming the public npm index.
- Extends registry discovery in project utilities and documents the new resolver APIs in the package README.
- Updates binary install helpers and tests so release tooling and `bin.ensure` stay aligned with registry-aware resolution.

### Model proxy (`dbx model-proxy`)

- Introduces a Tauri-based desktop app with a React UI and generated IPC bindings, replacing the previous embedded metrics-ui static bundle.
- Refactors the Rust crate into a shared library surface plus dedicated desktop and operator modules; metrics, routing, and rate-limit code paths were adjusted to support in-process desktop control.
- Simplifies the system tray menu for quicker access to common actions.
- Updates the JavaScript CLI, README, and tests for desktop-related commands and behavior.
- Adds repository scripts and Projen tasks to build desktop assets and generate bindings; removes the old metrics asset packaging script.

### Service lifecycle (`dbx-tools-service`)

- Adds `dbx-tools-service-desktop`, a reusable Tauri shell crate for tray, window, and capability probing.
- Moves desktop-specific logic out of the core service crate; service README and manifests reflect the slimmer split.

### Native release binaries (`@dbx-tools/rust-binary`)

- Adjusts release binary metadata and install flow so the model proxy can ship and select the desktop executable alongside the headless binary.

### Monorepo and release

- Bumps workspace versions and lockfiles across Rust and JavaScript packages for the unified 0.9.13 release.
- Tweaks the generated release workflow and release preparation tasks for the new desktop artifacts.
- Updates root and package documentation, archives a completed model-proxy rate-limit enhancement plan, and refreshes in-repo agent guidance.
