# Release 0.6.227

dbx-tools 0.6.227 updates AppKit and agent integrations, search components, and release tooling, with expanded test coverage and refreshed documentation.

**AppKit and Agents**
- Add AppKit auto-configuration and toolkit modules, plus lifecycle and packaged-consumer tests.
- Add a Mastra evaluation module and tests, and update Graphiti integration.

**Search**
- Update the Lakebase search plugin, search-box component, and styling.
- Add native-agent web-search fixtures and tests.

**Documentation and Tooling**
- Refresh AppKit, Mastra, search, and web-search documentation.
- Update workspace configuration and release-summary generation.
