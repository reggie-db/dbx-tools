## v0.9.162
Changes since `v0.9.161`, including HEAD and the working tree.

**Breaking Changes**
- Removed `destroyAfterStartupFailureSeconds` and `DBX_TOOLS_LAKEBOX_DESTROY_AFTER_STARTUP_FAILURE_SECONDS`. Remove these settings from application configuration. SSH startup failures no longer automatically delete and replace the Lakebox.

**Fixes**
- Lakebox startup retries refresh gateway metadata to follow address changes, retaining the existing five-minute retry window.
- Lakebox SSH connections now attempt public gateway addresses on `ECONNREFUSED`, in addition to existing network-unreachable and timeout errors.
- The demo no longer deletes and recreates its Lakebox after a 30-second SSH startup failure.

**Validation**
- The configured release validation phase completed before this review. Detailed results were not supplied; no additional tests or validation commands were run.
