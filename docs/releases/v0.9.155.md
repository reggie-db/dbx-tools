## v0.9.155
Changes since `v0.9.154`, including HEAD and working-tree changes; generated churn and test-only changes omitted.

**Breaking Changes**
- Individual TypeScript module subpaths are removed. Import from package roots or published folder subpaths; namespaces follow source filenames. Projen project classes move from `project` to `projectJs` / `projectPy`.
- Generated AppKit workspaces replace split app/server packages with one private application containing `client/` and `server/`. Configure its location with `appRoot`; Vite overrides belong in `client/vite.config.override.ts`.

**Fixes And Improvements**
- AppKit deployment supports nested application directories and preserves built client assets in the isolated upload snapshot.
- Generated Bun browser builds deduplicate React and support configurable entrypoints, output paths, source aliases, and TypeScript configuration.
- Barrel generation preserves merged type/value exports. Generated ESLint rules enforce relative imports within packages.

**Validation**
- The configured release validation phase completed, as reported. Detailed outcomes and counts were not supplied; no tests or validation commands were rerun.
