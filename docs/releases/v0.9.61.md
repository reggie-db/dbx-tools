**dbx-tools 0.9.61 - Unreleased**
Compared HEAD and the working tree against `v0.9.60`; generated churn and test-only changes excluded.

**Added**

- `dbx genie` and `dbx-genie` run pinned Genie Code with profile-scoped homes, model-specific invocation overlays, and an authenticated local model gateway.
- Authentication CLI supports plain-text tokens and JSON authentication headers.
- Releases generate notes through Genie with a git-log fallback; `--no-release-notes` skips generation. Demo deployment is available through `bun run demo:deploy` or release option `--demo-deploy`.

**Fixes**

- Forwarded CLI commands preserve child flags and arguments.
- Model gateway corrects Codex alias routing and removes unsupported upstream request fields. GPT family searches no longer let GPT-OSS parameter sizes outrank hosted GPT generations.
- Mastra fixes feedback submission for Unity Catalog traces and trace-ID delivery to chat clients; traces include user, session, and Genie-call metadata.
- Chat UI moves Genie thinking into collapsed Thoughts, keeping query tables and intermediate answers in tool details.

**Breaking Changes**

- No breaking public API removals identified. GPT alias selection and Codex routing change as described above; specify an exact model or serving endpoint when selection must remain fixed.
