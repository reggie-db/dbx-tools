## v0.9.179

### Improvements and Fixes
- Model selection adds quality, speed, and cost preferences plus structured-output filtering. Chat-only resolution avoids unnecessary embedding-dimension probes.
- Chat thread titles generate alongside responses using a bounded, speed-optimized model. Chat stays in the finishing state until title delivery and thread synchronization complete, preventing stale sidebar titles and premature completion.
- Automatic follow-up suggestions use bounded request and answer text, capped output, and structured-output-capable models. Automatic generation no longer includes tool payloads.
- Feedback routes per message to Genie or MLflow when available, with direct thumbs ratings and optional written feedback. Authorized viewers can open the specific MLflow trace from a response.

### Breaking Changes
- Custom Mastra clients and chat views must replace `feedbackMode` with a `feedbackModes` array; `[]` disables feedback. Server configuration retains `feedbackMode`.
- Custom `AssistantBubble` consumers must replace `mlflowExperimentUrl` with `mlflowTraceUrl`.

### Validation
- Configured release validation completed before this review. No additional tests or validation commands were run.
