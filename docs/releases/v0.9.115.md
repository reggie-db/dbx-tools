**v0.9.115**
Changes since `v0.9.114`, including HEAD and the working tree:
- **Image attachments:** Mastra chat supports up to four images per message, with previews, removal, and image-only submissions. Images over 4 MiB are automatically resized and compressed before sending.
- **Fixes:** Chat displays attached images and preserves them through queued messages and “send now.” Image-only messages use filenames for provisional thread titles.
- **UI:** Export and clear-history controls use compact icon buttons with tooltips.
- **Breaking changes:** `ChatViewProps.sendMessage` accepts `ChatInputMessage`, whose `text` is optional and whose `files` contain AI SDK file parts. Custom handlers and `QueuedSteer` consumers must handle missing text and image-only messages.
- **Validation:** The configured release validation phase completed, as reported. Detailed results and counts were not supplied; no tests or validation commands were rerun.

Generated-file churn and test-only changes are excluded. No files were modified.
