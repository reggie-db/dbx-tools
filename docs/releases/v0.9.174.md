## v0.9.174

Cumulative changes since `v0.9.173`, including the working tree.

**Improvements And Fixes**
- Documentation gains a resizable desktop sidebar with saved width, keyboard controls, and reset support. Selecting a page no longer changes label wrapping.
- Documentation diagrams use theme-aware colors and more compact layouts.
- Python’s Node compatibility runtime returns a Node-style `ENOENT` result when `spawnSync` cannot find an executable, instead of propagating a Python exception.
- Projen-generated workspaces retain a registry-neutral `bun.lock` and use frozen-lockfile CI installs. Automatic normalization removes detected private-registry tarball URLs while preserving integrity hashes and each machine’s registry selection.

**Breaking Changes**
- Generated CI installs now require a committed, up-to-date root `bun.lock`; manifest changes without a matching lockfile update fail installation.

**Validation**
- The configured release validation phase completed before this review; detailed results and counts were not supplied. No tests or validation commands were rerun, and no files were modified.
