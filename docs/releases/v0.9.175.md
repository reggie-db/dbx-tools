## v0.9.175

Cumulative changes since `v0.9.174`, including the working tree.

**Improvements And Fixes**
- CLI services stop their full process tree, preventing orphaned child processes. Longer shutdown windows give services more time to clean up, including on macOS.
- Graphiti shutdown continues closing database and HTTP resources even when another cleanup step fails, while preserving the original error.
- Embedded Graphiti PostgreSQL removes stale process handles that could prevent automatic shutdown. Graphiti also limits graceful request shutdown to five seconds.
- `@dbx-tools/core` adds `shutdownProcessTree()` for callers using native Node child processes.
- Documentation publishes after selected package publishers succeed, without waiting for public registry availability. Registry verification remains required for release workflow success.

**Breaking Changes**
- No breaking changes identified.
