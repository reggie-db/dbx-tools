## v0.9.126
Compared HEAD and the working tree with `v0.9.125`; generated churn and test-only changes are excluded.

**Breaking Changes**
- Sandbox project `config.hooks.postinstall` must now be a string; other value types are rejected.

**Fixes**
- Sandbox project creation, opening, terminal access, reset, and deletion now start stopped machines and wait for the running state.
- Project installation now verifies successful postinstall completion, preventing failed hooks from being reported as successful installs.
- The network-speed-test recipe launches LibreSpeed through mise using the correct `speedtest-backend` executable.
- `bun run slop:review` honors generated `.gitignore` exclusions, avoiding scans of ignored directories.

**Validation**
- The configured release validation phase completed before this review, as reported. No validation commands were rerun; detailed results and counts were not provided.
