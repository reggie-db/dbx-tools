**v0.9.118**
Changes since `v0.9.117`, including HEAD and the working tree.

**Breaking Changes**
- Databricks agent sandboxes now default to the active request’s credentials, including user OBO, rather than a fresh service-principal client. Set `client` explicitly to retain service-principal execution.

**Fixes**
- Mastra model discovery and inference fall back to configured service-principal credentials outside a request, while preserving request-scoped OBO.
- Enable durable chat-run status reads and cancellation through the Mastra API gate.
- Exclude previous `render_data` calls and results from subsequent model prompts while retaining them in memory and the UI transcript.
- New release workflows cancel older in-progress releases to prevent overlapping publication.

**Validation**
- Configured release validation completed before this review, as reported. Detailed outcomes and counts were not provided; no tests or validation commands were rerun.
