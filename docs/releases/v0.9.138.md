**v0.9.138**
Changes since `v0.9.137`, including HEAD and the working tree.

**Fixes**
- Demo deployment preserves existing catalog permissions by adding app service-principal grants instead of replacing the catalog’s grant configuration.
- Grants `USE_CATALOG` and `CREATE_SCHEMA` after the app resource exists and before starting it.
- Validates deployment configuration and the returned service-principal ID before updating permissions.

**Breaking Changes**
- Custom demo deployment flows using only bundle commands must now grant the app’s catalog permissions separately; `demo:deploy` handles this automatically.

**Validation**
- Configured release validation completed before this review; detailed results were not provided. No tests or validation commands were rerun.
