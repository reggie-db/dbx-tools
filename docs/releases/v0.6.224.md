# Release 0.6.224

dbx-tools 0.6.224 fixes model proxy streaming usage parsing and improves shared runtime contracts, package generation, and publishing.

**Runtime**
- Fixes usage parsing for native server-sent event (SSE) streams in the model proxy.
- Extracts Rust binary support into a dedicated package.
- Hardens shared runtime contracts and adopts public parser and migration APIs.

**Build and Publishing**
- Uses native structured generators and structurally updates local Cargo dependency versions.
- Compares canonical npm package content while ignoring non-executable file mode differences.
- Fixes local UniFFI TOML parser resolution and generates portable package tasks.
- Hardens external consumer contracts, with new tests for external projects and packed-package consumers.
