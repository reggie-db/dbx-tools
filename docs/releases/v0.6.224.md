# Release 0.6.224

dbx-tools 0.6.224 focuses on runtime fixes, reusable Rust binary tooling, and more reliable package generation and releases.

**Runtime**

- Fix native SSE usage parsing in the model proxy.
- Move Rust binary support into a dedicated reusable package, separating it from CLI code.
- Harden shared runtime contracts and reuse public parsers and migration APIs.

**Build and Packaging**

- Use native structured generators, make generated package tasks portable, and strengthen compatibility for external consumers.
- Compare canonical npm package content while ignoring non-executable file mode differences.
- Stamp local Cargo dependencies structurally and fix local UniFFI TOML parser resolution.
