## v0.9.191
Cumulative changes since v0.9.190, including the working tree.

**Features**
- Adds side-by-side model comparison with shared prompts, Smart Router, AI Decide, persisted conversations, and per-model metrics.
- Adds AI Decide routing with balanced, quality, cost, and latency strategies; task-complexity assessment helps select sufficient models.
- Adds model token pricing, latency benchmarks, and LMArena quality ratings. Gateway clients can request enriched catalogues with `metadata=true`.
- Adds per-turn selected-model display, token usage, elapsed time, and estimated DBU/USD costs, plus browser-persisted history for agents without Mastra memory.

**Fixes**
- Preserves multi-turn browser context and restores model telemetry from saved conversations.
- Fixes chat overflow in narrow comparison panes.
- Adds authentication-readiness checks and automatic restart backoff for installed services, improving startup before network or VPN access is ready.

**Breaking Changes**
- Moves `CloudProvider` from `@dbx-tools/databricks` to `@dbx-tools/shared-core`.
- Automatic model ranking now defaults to foundation models; callers selecting custom deployments must explicitly target them or set `modelSource: "custom"`.

**Validation**
- Configured release validation completed, as reported. No additional validation commands ran; no files changed.
