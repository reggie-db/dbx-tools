## v0.9.182

### Fixes
- Fix Mastra ratings and written feedback for Unity Catalog–backed MLflow traces, preserving attribution to the signed-in user.
- Fix Debug links to open the selected trace and show them to users with experiment read access, rather than requiring manage permission.
- Stabilize mobile chat keyboard transitions, composer positioning, transcript scrolling, and jump-to-bottom behavior.
- Improve suggestion layouts, focus the composer when starting a conversation, and prevent feedback dialogs from leaving pointer-triggered focus behind.
- Keep response progress and actions attached to the latest visible assistant response through finalization.

### Breaking Changes
- Custom chat integrations must replace `scrollToBottom` with `scrollToBottomNow` and `onSelectFollowUp` with `onSelectSuggestion`. Direct `ChatComposer` consumers must supply `focusRequest`; its `isEmpty` and `suggestions` props are removed.
- MLflow experiment responses now require nullable `tracePrefix`.

### Validation
- Configured release validation completed before this review. No tests or validation commands were rerun; notes reflect `v0.9.181..HEAD` plus the working tree.
