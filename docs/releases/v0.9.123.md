## v0.9.123
Changes since `v0.9.122`, including HEAD and the working tree; generated churn and test-only changes omitted.

**Breaking Changes**
- Generated install tasks now require Bun 1.4.2 or newer. Use `bun run bun` to select the pinned workspace-local binary.
- `SshRuntime.disconnect()` now returns `Promise<void>`; await it before relying on completed session and route cleanup.

**Fixes**
- Sandbox SSH shutdown cleans up pending connections and native OpenSSH processes, including when the parent process exits unexpectedly.
- HTTP/WebSocket forwarding retries a failed channel open once on a fresh connection without replaying established streams; fixes timeout and socket-cleanup handling.
- Serializes route changes to prevent shutdown races and prevents concurrent processes from publishing mismatched SSH keys.
- Tunnel supervisors stop retrying during parent termination instead of treating shutdown as a crash.
- Mastra chat and tool-output links gain clearer contrast and keyboard-focus styling.

**Validation**
- The configured release validation phase completed before this review. Detailed results and counts were not supplied; no tests or validation commands were rerun.
