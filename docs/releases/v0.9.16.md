# Release 0.9.16

Release 0.9.16 is a coordinated monorepo version bump focused on release automation and contributor tooling. Application APIs are largely unchanged; most visible updates are in how Rust artifacts are built and how packages are published during release preparation.

### Versioning
- Every workspace package and the Rust workspace align on version 0.9.16.

### Rust releases and native artifacts
- Rust release builds use separate UniFFI and binary matrices instead of a single combined matrix, with updated release metadata (`.release/rust-uniffi.json`, `.release/rust-binaries.json`) and matching GitHub Actions and Projen generator changes.
- Release helper scripts and tests were updated for the split matrices and content-addressed reuse workflow.

### npm, PyPI, and local publication
- Release publication logic was reorganized: dedicated Python publishing and Python registry helpers, local publish orchestration, and UniFFI-focused local publish tasks replace the previous Cargo packaging path (`package-cargo` removed).
- npm publish task behavior was adjusted as part of the same release pipeline work.
- Earlier experiments with strictly sequential registry dependency publication and finalized publication ordering were reverted in this line of development; the shipped workflow reflects the post-revert state.

### Documentation site
- The planned GitHub Pages per-package index generator was reverted and removed (`generate-package-indexes` scripts deleted). This release does not add those browse-by-package index pages.

### Docs and examples
- `AGENTS.md`, Projen `README.md`, and enhancement plan docs were updated to match current release behavior.
- Example AppKit demo package metadata and example README were refreshed for the release.

### Generated and registry surfaces
- Regenerated OpenAPI artifact for `@dbx-tools/openapi-model-proxy` (minor spec refresh).
- Root and Rust crate manifests received small release-related metadata updates consistent with the unified version.
