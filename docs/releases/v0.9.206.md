## v0.9.206
Cumulative changes since `v0.9.205`, including the working tree.

**Fixes And Improvements**
- Compile, test, and packaging tasks consistently use Projen’s recorded workspace members, preventing disagreement with root `package.json` workspace entries.
- Workspace publishing rejects missing or unreadable package manifests instead of silently skipping them.
- Development watchers reuse package discovery and change-selection results, reducing repeated work during rebuilds.
- AppKit TypeScript configuration uses native Projen components while retaining client and server compiler settings.

**Breaking Changes**
- `@dbx-tools/projen` now requires Projen `^0.104.26`.
- Compile, test, and manifest-materialization tasks no longer discover packages solely from root `package.json`; record members in `pnpm-workspace.yaml`.

**Validation**
- The configured release validation phase completed, as reported. No tests or validation commands were rerun; no validation counts are claimed. No files were modified.
