# Release 0.9.14

Release 0.9.14 is a coordinated workspace version bump that refocuses the model proxy on a headless service with an optional tray companion, expands its machine-readable API surface, and extends the release pipeline so package indexes for the documentation site are built and published from GitHub Actions.

### Model proxy

- Removes the Tauri-based desktop operator UI, the `service-desktop` crate, and the `model-proxy-desktop` helper script; the proxy ships as the Rust binary plus CLI integration updates in `@dbx-tools/cli-model-proxy`.
- Adds a `dbx-model-proxy-tray` companion binary and tray support routed through `dbx-tools-service` for installed, user-scoped background use.
- Grows the HTTP surface (routing, streaming, rate limiting, runtime, and metrics) and adds structured request/event plumbing used for observability and tooling.
- Publishes a new generated `@dbx-tools/openapi-model-proxy` package (OpenAPI spec, TypeScript schema, and fetch client) wired through the Projen OpenAPI pipeline.
- Updates the native release registry in `@dbx-tools/rust-binary` for the new binary layout.
- Improves CLI tests so ambient profile fallback behavior is isolated in model-proxy tests.

### Documentation site and package indexes

- Adds `docs/scripts/generate-package-indexes.mjs` (with tests) to produce package index artifacts for the site.
- Extends the generated `release.yml` workflow so those indexes (along with existing docs publication) are produced in CI rather than relying on removed local publish helpers.

### Release and Projen tooling

- Consolidates publication tasks: removes separate local Python registry, local UniFFI publish, and standalone `publish-python` / `python-registry` paths in favor of updated npm, Python stamping, and a new `package-cargo` task for Cargo index generation.
- Refreshes Rust release workflow generation, workspace lock handling, barrel generation, and OpenAPI export for Rust producers (including model-proxy).
- Updates contributor docs in `AGENTS.md`, `projen/README.md`, and related enhancement notes.

### Shared libraries

- Adjusts `@dbx-tools/shared-core` object helpers with matching unit test coverage.

### Examples and workspace metadata

- Bumps all workspace `package.json` / manifest versions to 0.9.14, including the AppKit demo example packages and `pnpm-workspace.yaml` membership for the new OpenAPI package.
- Minor README and example documentation touch-ups.
