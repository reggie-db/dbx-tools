# Release 0.9.21

This release focuses on reliability for streaming responses in the model proxy, adding protection against SSE connections that stop producing data.

## Model Proxy

- Bounded idle SSE streams so an upstream connection that stops sending data no longer hangs indefinitely.
- Added supporting logic across stream handling, request logging, and routing to detect and close inactive streams.
- Updated the model proxy README to document the new idle stream behavior.

## Documentation

- Updated `AGENTS.md` with guidance reflecting the new idle stream handling in the model proxy.
