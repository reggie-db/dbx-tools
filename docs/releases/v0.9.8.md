# Release 0.9.8

This release expands the model proxy with a dedicated CLI, background service and desktop companion, richer metrics and rate-limit behavior, and shared Rust service lifecycle support. Core Databricks authentication and profile handling improve, Node helpers for binary install and file locking are updated, and release or workspace tooling picks up the new Rust crate and binaries.

### Model proxy

- New `@dbx-tools/cli-model-proxy` package exposes model-proxy commands through the main `dbx` CLI.
- New `dbx-model-proxy-desktop` binary and metrics UI assets support a desktop companion and updated dashboard.
- Large updates to runtime management, HTTP routes, metrics collection, throttling, and rate limiting, including adaptive rate-limit behavior.
- Postman collection and health-check fixtures updated for the proxy API surface.
- Model proxy README and package metadata expanded.

### Service lifecycle (`dbx-tools-service`)

- New Rust `packages/rs/service` crate with desktop tray integration and shared install, SQLite, and lifecycle logic consumed by model proxy.
- Projen and release catalog wiring register the crate, tasks, and release workflow steps for the new binary.

### Databricks core (Rust)

- Authentication and profile modules refactored with config file and resolution changes.
- `DatabricksClient` and runtime helpers updated; core README documents new behavior.
- Model catalogue client adjustments in `packages/rs/model`.

### JavaScript platform

- `@dbx-tools/core` improvements to `bin.ensure` style binary handling and cross-process `fileLock` behavior, with matching tests.
- `@dbx-tools/core-rs` bindings regenerated for core changes.
- `@dbx-tools/rust-binary` release registry and install paths updated for additional native binaries (including model proxy desktop).

### Graphiti (Python)

- Small runtime and settings tweaks with test updates.

### Tooling and docs

- Projen: workspace-wide file lock for sync and release, Rust project generator updates, release PR task refactor, and local UniFFI publish adjustments.
- Root README, agent package catalog, and AGENTS.md updated; enhancement notes cover model proxy menubar icons and adaptive rate-limit decay.
- GitHub release workflow and model-proxy metrics asset validation script updated.
- Workspace adds the new CLI package to `pnpm-workspace.yaml` and root `package.json` dependencies.
