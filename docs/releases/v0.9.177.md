## v0.9.177

### Improvements And Fixes
- Keep chat streams alive during startup and quiet periods, reject unavailable background runs, and report interrupted streams instead of silently accepting incomplete answers.
- Stop the response indicator when the answer finishes while retaining turn ownership during post-processing, preventing queued messages from overlapping.
- Restore generated follow-up suggestions and keep thread titles and other fast-tier tasks from inheriting the primary agent’s model selection.
- Coalesce Smart Router selection within a request, skip redundant probes for explicit routing, and scope model discovery caches by user identity.
- Add `refreshAfterWrite` caching: serve cached values while one background reload runs, retaining the previous value if refresh fails.
- Route compatible Chat Completions requests to the concrete Databricks serving endpoint.
- Pre-index native skills at startup and content-address vendored workspace archives so deployments pick up changed packages at the same version.

### Breaking Changes
- `ChatStatus` adds `"finishing"`; update exhaustive status handling.
- Automatic completed-turn saving no longer starts Graphiti. Set `saveTurns: true` to retain that behavior.
- The demo makes semantic recall and remote AI Tools skills opt-in via `MASTRA_MEMORY` and `REMOTE_SKILLS_ENABLED`; thread storage remains enabled.
