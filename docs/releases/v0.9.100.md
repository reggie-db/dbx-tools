## v0.9.100
Changes since `v0.9.99`, including HEAD and the working tree. Generated-file churn and test-only changes are excluded.

**Breaking Changes**
- Move imports from `@dbx-tools/model/serving-wire` and `@dbx-tools/appkit-mastra/serving-sanitize` to `@dbx-tools/model-protocol/serving-wire`.
- Mastra’s default `providerId` changes from `databricks` to `openai`; update provider-specific options accordingly. Shared AI SDK dependencies move to version 7.
- Workspace tools no longer require approval by default. Configure `tools.requireApproval` explicitly where approval gates are needed.

**Features**
- Mastra turns now continue after browser disconnects by default, with stream reconnection and explicit server-side cancellation. Set `backgroundTurns: false` to retain request-bound execution.
- Add `@dbx-tools/model-protocol` for request-scoped Chat Completions, Responses, and Anthropic providers without modifying global `fetch`.
- Enable reasoning by default for supported models and add agent guidance for independent parallel tool calls.

**Fixes**
- Preserve request-scoped workspace credentials during background filesystem operations.
- Close completed chat streams promptly and prevent completed tool calls from remaining marked as running.
- Improve dark-mode syntax highlighting, branded control contrast, and mobile chat layout and keyboard handling.
- Fix Python binding path resolution through symlinked directories when target files do not yet exist.

**Validation**
- The configured release validation phase completed before this review; detailed results and counts were not supplied. No additional validation commands were run, and no files were modified.
