## v0.9.145
Changes since `v0.9.144`, including HEAD and the working tree.

**Breaking Changes**
- Removed `@dbx-tools/teams`, `@dbx-tools/shared-teams`, and `@dbx-tools/ui-teams`, including the Teams AppKit plugin, agent tool, messaging routes, and Adaptive Card UI. Remove these dependencies and integrations before upgrading.

**Fixes**
- Keep Mastra agent execution attached to its chat trace; suppress standalone traces from background HTTP calls such as discovery, token refresh, and usage telemetry.
- Attribute AppKit HTTP traces to the forwarded user’s email, falling back to user ID.
- Resolve MLflow Unity Catalog trace locations from experiment tags or `trace_location`; retry failed startup discovery with the request user’s client while retaining service-principal trace-info writes.
- Keep tool-output Markdown text consistently compact across paragraphs, lists, links, bold text, and code.

**Validation**
- Configured release validation completed before this review. Detailed results and counts were not provided; no tests or validation commands were rerun.
