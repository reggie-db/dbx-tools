**v0.9.94 — Changes Since v0.9.93**
Includes HEAD and working-tree changes; excludes generated churn and test-only changes.

**Breaking Changes**
- Mastra adopts native workspace skills. Replace `workspaceSkillSearch` with `workspaceSkills`; `workspaceSkillRefreshTtlMs`, `skill-cache`, and `skill-search` APIs are removed.
- Default skill mounts use actual `/Workspace` paths instead of named aliases. Update hard-coded paths; configure approvals through `workspaceTools`.
- Demo deployment now requires `--profile <name>`, including `release --demo-deploy`.

**Features And Fixes**
- Adds user-isolated filesystem caching with cross-user invalidation and request-current OBO credentials. Skill-content caching is scoped to configured skill roots.
- Adds service log access, local Python-project installation, and offline installation; introduces a shared development watcher.
- Reuses Lakebase credentials until shortly before expiry and coalesces concurrent refreshes.
- Fixes duplicate/stale Mastra approval resumes and adds readable tool-input previews.
- Improves Graphiti runtime selection and startup/shutdown handling; fixes natural-language PostgreSQL search parsing and executable paths containing spaces.

**Validation**
- Configured release validation completed before this review, as reported. No validation commands were rerun; detailed results and counts were not supplied.
