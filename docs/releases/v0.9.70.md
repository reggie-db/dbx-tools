**v0.9.70**
Changes since `v0.9.69`, including HEAD and the working tree; generated churn and test-only changes excluded.

**Breaking Changes**
- Mastra traces now set `agent` to the first selected model ID instead of `"true"`; the separate `model` tag is removed. Update trace filters and consumers. `MLFLOW_MODEL_TAG`, `MLFLOW_MODEL_TAG_ATTR`, and `modelTraceTag` are removed.
- `ProjectContext.output` is now optional, and `success` is required.
- The demo defaults to automatic authentication: OBO through the Databricks Apps front door, service-principal fallback through the OTP tunnel. Deployment uses the configured/default profile rather than a pinned workspace.

**Improvements And Fixes**
- Demo deployment packages locally compiled Node artifacts and Python wheels, so current-checkout deployment no longer waits for npm/PyPI publication.
- Release tagging selects a repository-accessible GitHub account, falls back to Git push when API creation fails before the remote tag exists, and synchronizes the local annotated tag with the remote object.
- Added configurable process-tree shutdown with graceful termination, forced cleanup, descendant tracking, and PID-lifetime checks.

**Validation**
- The configured release validation phase already completed. Detailed results and counts were not supplied; no additional validation ran, and no files were modified.
