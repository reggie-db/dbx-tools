# Release 0.9.7

Release 0.9.7 builds on 0.9.6 with stronger model-proxy rate limiting and observability, safer GitHub release asset cleanup, clearer docs and generated-code presentation, and small fixes across tunnel, shared utilities, and contributor tooling.

### Model proxy
- Adds gradual rate limiting across adaptive throttling, rate-limit gates, streaming, routing, metrics, and request logging.
- Expands the metrics dashboard assets and README to match the new limiter behavior and UI.
- Adjusts error handling and main startup wiring tied to the updated limiter flow.

### Model catalogue (Rust)
- Updates endpoint resolution and related tests in the shared model crate used by the proxy and bindings.

### Release and CI
- Prunes only older release assets so superseded Rust bundles and related GitHub release files are removed without touching the current version.
- Updates the generated release workflow and Projen release helpers that drive publication and Rust matrix packaging.

### Documentation and API site
- Adds a dbx-tools reuse agent skill with a package catalog reference and a generator script for agent skills.
- Highlights embedded generated code in API doc generation and related barrel or app build output.
- Refreshes root, AGENTS, Projen, and multiple package READMEs to describe current behavior directly rather than migration history.
- Shortens and clarifies tunnel CLI documentation and status examples.

### Tunnel
- Revises the hosted login page and Portr integration in the tunnel package.

### Shared core
- Extends string utilities with new behavior and tests; README notes the updated helpers.

### Contributor tooling (Projen)
- Adjusts sync, OpenAPI generation, Python project synthesis, Bun app and workflow helpers, and Rust release workflow tests to align with release and docs changes.

### Other
- Tweaks process-lock tests in `@dbx-tools/core`.
- Minor README touch-ups for auth CLI, dbx-tools CLI, appkit, appkit-mastra, appkit-graphiti, email, genie, and Rust core.
