## v0.9.154
Changes since `v0.9.153`, including HEAD and the working tree.

**Breaking Changes**
- Graphiti Lakebase startup rejects schemas not owned by `POSTGRES_ROLE`, or by the login when no role is configured. The new `prepare_lakebase_schema()` helper can recreate a login-owned schema under a distinct shared role; this deletes existing schema objects.
- `syncThreadTabs()` replaces its numeric fourth argument with an options object: use `{ seedMax: n }`.

**Fixes**
- Mastra uses a dedicated Lakebase pool so concurrent plugin shutdown does not interrupt final durable workflow snapshot writes.
- Closing all conversation tabs no longer automatically reopens recent conversations.

**Release Reliability**
- Public releases wait for exact npm tarball contents and PyPI distribution hashes to become available before documentation deployment or workflow success. Local publishing is unchanged.

**Validation**
- The configured release validation phase completed, as reported. No tests or validation commands were rerun; detailed results and counts were not provided.
