## v0.9.190
Changes since `v0.9.189`, including the working tree.

**Features And Fixes**
- AppKit Lakebase provisioning now covers existing `appkit` and `mastra_instance` schemas, with additional schema or `schema.table` targets configured through `lakebaseProvisionTargets` or `DBX_TOOLS_APPKIT_LAKEBASE_PROVISION_TARGETS`.
- Grants run transactionally per target. Explicit table grants remain fallbacks when schema-wide grants fail; missing targets are skipped, and grant failures do not prevent remaining targets from being attempted.
- The demo now includes `sharp`, enabling optional Genie chart-image enhancement.

**Breaking Changes**
- Replace `provisionCacheSchema(role, logger)` with `provisionLakebaseAccess(role, targets, logger)`, and `cacheGrantStatements(role)` with `lakebaseGrantStatements(target, role)`. Default provisioning now includes `mastra_instance` alongside `appkit`.

**Validation**
- Configured release validation completed before this review, as reported. No tests or validation commands were run during this review.
