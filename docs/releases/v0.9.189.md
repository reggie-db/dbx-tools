## v0.9.189
Changes since `v0.9.188`, including the working tree.

**Features And Fixes**
- Genie PNG charts support click-to-enlarge viewing. Optional `sharp` processing upscales and sharpens chart images, falling back to the original PNG if unavailable or unsuccessful.
- AppKit workspace calls, Lakebase discovery, and persistent-cache connections share the selected profile’s authentication lifecycle, allowing expired CLI credentials to trigger login rather than falling through to unrelated SDK authentication.
- Bun lockfile normalization is available as a reusable `BunLockfile` Projen component and standalone `dbx-tools-bun-lockfile` executable.
- Published sibling-package dependencies use exact lockstep versions, preventing installs from mixing incompatible `@dbx-tools` releases.

**Compatibility**
- `BUN_LOCKFILE_TASK` moves from `projectJs` to `bunLockfile`; its top-level export remains available. Genie PNG downloads may return enhanced images rather than byte-identical originals.

**Validation**
- Configured release validation completed before this review, as reported. No tests or validation commands were run during this review.
