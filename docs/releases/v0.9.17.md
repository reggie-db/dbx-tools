# Release 0.9.17

This patch release tightens release automation so generated Rust matrix workflow output uses consistent line endings, which keeps release workflow files stable across platforms and regenerations.

## Release automation

- Normalized line endings in the GitHub Actions release workflow matrix configuration.
- Updated the Projen Rust release workflow generator to emit the same normalized matrix formatting.
- Adjusted Rust project workflow tests to match the generated output.

## Package consumers

- No application runtime, CLI behavior, or public API changes are included in the changes listed for this release.
