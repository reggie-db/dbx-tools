# Release 0.9.4

This release tightens the Rust release pipeline so published native binaries and bindings build more reliably and reuse work across releases when crate sources have not changed.

### Rust release artifacts
- Fixes retention of raw Rust release bundles so release jobs can attach and reuse complete matrix outputs instead of losing bundle data during publication.

### Release workflow
- Updates the generated GitHub release workflow to align with the retained raw bundles and workspace caching behavior.

### Build performance
- Adds synthesis of Rust workspace cache settings so CI can restore dependency and workspace crate outputs consistently.
- Enables caching of unchanged workspace crates when an exact raw-bundle hit is unavailable, reducing redundant compiles on release matrix builds.

### Contributor documentation
- Refreshes agent and enhancement-plan notes for singular-version, content-addressed Rust release reuse and cache policy so contributor guidance matches the workflow.
