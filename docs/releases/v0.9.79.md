## v0.9.79
Changes since `v0.9.74`, including HEAD and working-tree changes.

**Breaking Changes**
- Auto-created Mastra workspaces now default to Monty. Set `sandbox: true` or `"databricks"` to retain Databricks Sandbox execution.
- `workspaceSkillSearch: false` now disables skill tools instead of enabling eager catalogue injection.
- Removed `AppKitCachedFileSystem` and `cachedWorkspaceSkillMount`; use `WorkspaceSkillCatalogue` and `workspaceSkillCatalogue`. `workspaceSkillRefreshTtlMs` now controls catalogue refreshes, not individual file caching.

**Improvements And Fixes**
- Adds user-scoped, persistent skill catalogues with keyword search, on-demand instructions, fresh auxiliary-file reads, and last-valid fallback when refresh fails.
- Adds bounded in-memory caching to reduce warm Lakebase requests and bound Genie suggestion-cache growth.
- Remote skill refreshes remove obsolete directories and invalidate workspace catalogues.
- Fixes MLflow ESM imports and Monty 1.0 timeout compatibility; recovers missing Monty native bindings and explicitly includes the Linux binding in demo deployments.
- Logs failed agent tool calls and simplifies workspace-tool labels in chat.

**Validation**
- Configured release validation completed before this review. No tests or validation commands rerun; no validation counts provided.
