# Release 0.6.225

dbx-tools 0.6.225 updates AppKit Mastra model selection and expands release-summary tooling.

**Chat and Models**
- Adds live default-model resolution in AppKit Mastra.
- Moves Genie mode into the chat model menu.

**Release Tooling**
- Adds optional AI-generated release summaries with configuration and streaming support.
- Retains versioned release summaries.
- Includes the release version in workflow run names.
