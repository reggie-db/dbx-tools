## v0.9.161
Changes since `v0.9.160`, including HEAD and working-tree updates.

**Features And Fixes**
- AppKit deployments bundle transitive runtime workspace dependencies, avoiding waits for matching public package releases.
- Lakebox adds opt-in destructive startup recovery through `destroyAfterStartupFailureSeconds` (5–600 seconds). Replacement is coordinated across replicas; recovery is disabled by default and enabled at 30 seconds in the demo.
- npm publishing recovers from previously staged-version conflicts by waiting for matching public metadata and tarball content instead of republishing. Publication verification now allows 20 minutes.
- Canceled release workflows no longer continue downstream publishing, verification, or documentation deployment.
- Generated lint configuration includes custom AppKit application roots; Prettier correctly excludes generated files in nested projects.

**Breaking Changes**
- None identified.

**Validation**
- The configured release validation phase completed before this review. Detailed results and counts were not supplied; no additional validation commands were run.
