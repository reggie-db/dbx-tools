# Release 0.9.12

Reviewing the changed files to draft an accurate release summary.


**dbx-tools 0.9.12** is a focused **dbx-model-proxy** release. Completion logging is easier to read and to wire into metrics, with clearer protocol labels and more consistent log levels, without changing request handling behavior.

### dbx-model-proxy logging

- Default **info** completion lines now report the client and upstream protocol as plain lowercase wire values (for example `chat`, `responses`, `anthropic`, `auto`), not Rust debug forms like `Some(...)` / `None`.
- **Embeddings** completions label the client side as `embedding` and the target as `invocations` when no chat/responses pair applies.
- **Warn** is used for upstream **5xx** responses and for stream completions marked as failed; successful finishes and client-side stream cancellation stay at **info**.
- **Debug** still carries the full operational detail (peer, bytes, token estimates, throttle state, attempts); **info** stays a compact, payload-free summary (resolved model, route, protocol pair, streaming, status, duration).

### Metrics

- Prometheus request counters label **client_protocol** and **target_protocol** with the same lowercase wire strings used in logs, so dashboards and log queries stay aligned.

### Documentation

- **model-proxy** README and repository **AGENTS.md** describe the completion log shape, protocol label rules, and which events appear at info versus warn versus debug.
