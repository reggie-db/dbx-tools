# v0.9.93
Compared HEAD and the working tree with the latest tag, `v0.9.79`; generated churn and test-only changes excluded.

**Breaking Changes**
- Removed `@dbx-tools/appkit-mastra/monty-native`, its namespace, helpers, and installer types. Use `MontySandbox`; runtime native-package installation is no longer performed.

**Fixes**
- Monty sandbox falls back to WASM when native loading or pool creation fails; `MONTY_FORCE_WASM` selects WASM explicitly.
- AppKit demo launches with Node and `tsx` through `app.yaml`, fixing missing-start-script failures outside bundle launches. Deployment environment bindings remain in `databricks.yml`.
- Demo staging applies published package exports and pins nested workspace dependencies to local archives, avoiding registry resolution for those packages.
- Demo deployment refreshes authentication with interactive login fallback.
- Mastra code highlighting recognizes `text`, `plaintext`, and `txt` blocks.

**Validation**
- Configured release validation completed before this review, as reported. No tests or validation commands rerun; no result counts supplied. No files modified.
